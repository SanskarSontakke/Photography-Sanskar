# Sanskar Sontakke | Photography Portfolio

A high-end, creative photography portfolio website built with Next.js 15, Tailwind CSS v4, and Framer Motion.

## Features

- **Premium Design**: Dark mode aesthetic, Oswald typography, and custom cursor.
- **Interactive Elements**: Parallax hero, magnetic slider, and hover effects.
- **Responsive**: Fully optimized for mobile and desktop.
- **Performance**: Static site generation for fast load times.

## Getting Started

1.  Clone the repository.
2.  Run `npm install`.
3.  Run `npm run dev` to start the local server.

## Technologies

- [Next.js](https://nextjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Lucide Icons](https://lucide.dev/)
